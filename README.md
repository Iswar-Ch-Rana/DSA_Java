# DSA in Java

A structured collection of Data Structures and Algorithms problems solved in Java, organized by topic.

|----|------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

## Prerequisites

- Java 11+
- Any Java IDE (IntelliJ IDEA, Eclipse, VS Code with Java Extension Pack)

## Running

Each file contains a `main` method and can be run independently:

```bash
javac src/a_8_BinarySearch/BinarySearch.java
java -cp src a_8_BinarySearch.BinarySearch
```
